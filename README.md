## Important security note
This is a static GitHub Pages frontend. The login is **not a secure authentication system** because the HTML/JavaScript is public and can be inspected. Do not use this implementation to protect private data or real-money gambling. A real deployment needs server-side authentication, authorization, secure password hashing, HTTPS, logging, legal/licensing controls and responsible-gambling safeguards.

## Publish on GitHub Pages
The publishing source should be `main` + `/(root)` and `index.html` must be in the repository root.
